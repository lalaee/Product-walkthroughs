# Umami — set up analytics for your website

**What it is:** Umami is privacy-first web analytics: traffic, sources and behaviour, without cookies.
**For:** People who run a website and want to start measuring it.
**Hook:** 

## The flow

- Sign in to Umami
- Add a website: its name and domain
- Open the website's settings and copy the tracking code
- Put the code on the site and visit it
- Back in Umami, the visit is there

## Checks

- Length: 20–40 s
- "Add website" by 8 s
- "copy the tracking code" by 24 s

# Coucou — connect it, then approve from the island

**What it is:** Coucou lives at the top of your screen, shows your Claude Code sessions, and lets you approve their permission requests in one click.
**For:** People who run Claude Code and want to approve it without switching to the terminal.

## The flow

- Mochi, at the top of the screen
- Claude Code isn't connected yet
- Settings → Install hooks: the exact diff
- Back up and write
- Connected
- A permission request in the island
- Allow
- Claude carries on

## Checks

- Length: 30–55 s
- "Install hooks" by 20 s
- "Allow" by 45 s

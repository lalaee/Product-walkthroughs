# Coucou — connect it to Claude Code

**What it is:** Coucou lives at the top of your screen and keeps an eye on your AI coding agent: each session, what it edits, and its permission requests.
**For:** People who run Claude Code and want to watch their sessions at a glance.

## The flow

- Coucou on screen, with Mochi
- Claude Code isn't connected yet
- Open Settings
- Install hooks: the exact diff
- Back up and write
- Back in the island: connected

## Checks

- Length: 25–45 s
- "Install hooks" by 22 s
- "connected" by 42 s
